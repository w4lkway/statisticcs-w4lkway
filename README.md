# Статистика w4lkway

Личный сайт со статистикой CS2, Dota 2 и Fortnite. Хостится на GitHub Pages, цифры обновляются сами раз в 6 часов.

## Как это устроено

- `site/index.html` страница сайта. Читает цифры из `site/data/stats.json`.
- `scripts/update.mjs` забирает свежие данные из API и записывает их в `stats.json`.
- `.github/workflows/update.yml` запускает скрипт по расписанию, сохраняет результат в репозиторий и публикует сайт.
- `config.json` ники и ID (не секретные).

## Откуда берутся данные

| Игра | Источник | Что обновляется само |
|---|---|---|
| CS2 | Steam Web API | часы в игре, уровень, возраст аккаунта, убийства по оружию |
| CS2 | FACEIT Data API | ELO, матчи, винрейт, K/D, HS%, последние 5 матчей, дата последнего матча |
| CS2 | Leetify API | Aim, Utility, рейтинг CT/T, последние матчи, форма в Premier |
| Dota 2 | OpenDota API | матчи, победы, винрейт, рейтинговые, лобби, режим, сторона, топ-10 героев с KDA |
| Fortnite | fortnite-api.com | матчи, победы, убийства, режимы Solo/Duos/Trios/Squads, места, время в игре |

**Почему не сами Dotabuff и трекеры.** У Dotabuff, Tracker.gg и подобных сайтов нет открытого API, а страницы закрыты защитой от ботов. Скрипт с серверов GitHub оттуда обычно получает отказ, и обновление ломалось бы через день. Поэтому вместо них берутся API, которые отдают те же данные: OpenDota показывает те же матчи, что и Dotabuff, Steam и FACEIT дают то, что показывает CS-трекер.

**Что остаётся ручным.** Эти поля в `site/data/stats.json` скрипт не трогает, потому что у них нет открытого источника. Их можно править прямо на GitHub (иконка карандаша у файла), сайт обновится сам:

- CS2: Scope.gg (`cs2.scope`), HS% по оружию (`cs2.weaponHs`), матчи и K/D Premier (`cs2.premier`), проценты «топ» у Aim и Utility, ADR/UDR/клатчи на FACEIT, если API их не отдаёт.
- Dota 2: роли кор/саппорт (`dota.roles`), регионы (`dota.region`), роль и линия у героев, ник профиля.
- Fortnite: разбивка Build / Zero Build (`fortnite.build`, `fortnite.zeroBuild`).

KDA героев считается как (убийства + помощь) / смерти по всем матчам, на Dotabuff формула может немного отличаться.

## Запуск за 10 минут

1. **Репозиторий.** Создай на GitHub новый репозиторий (публичный, например `w4lkway-stats`) и загрузи в него все файлы из этой папки, включая скрытую `.github`. Проще всего через GitHub Desktop или `git push`.
2. **Pages.** В репозитории: Settings → Pages → Source: **GitHub Actions**.
3. **Ключи** (бесплатные). Нужны только для тех источников, которые хочешь включить:
   - `STEAM_API_KEY`: https://steamcommunity.com/dev/apikey
   - `FACEIT_API_KEY`: https://developers.faceit.com (создай приложение, нужен Server side API key)
   - `FORTNITE_API_KEY`: https://dash.fortnite-api.com
   - `LEETIFY_API_KEY`: в кабинете Leetify, раздел для разработчиков (API). Если не нашёл, пропусти: остальное заработает без него.
   - `OPENDOTA_API_KEY`: не обязателен.
   
   Добавь их: Settings → Secrets and variables → Actions → New repository secret.
4. **Открой профили.** Без этого API ничего не отдадут:
   - Steam: Профиль → Настройки приватности → «Сведения об играх» = Открытые.
   - Dota 2: Настройки → Социальные сети → «Открытая история матчей» (Expose Public Match Data).
   - Fortnite: Настройки → Аккаунт и конфиденциальность → показывать статистику в таблице лидеров.
5. **Проверь `config.json`.**
   - `dotaAccountId`: если `null`, берётся из Steam ID. Открой `https://www.opendota.com/players/485728236`: там должен быть твой Dota-профиль. Если нет, впиши свой ID из ссылки на Dotabuff.
   - `epicName`: ник в Epic Games. Сейчас стоит `w4lkway`, поменяй, если он другой.
6. **Первый запуск.** Actions → Update stats and deploy → Run workflow. Через минуту сайт будет на `https://ТВОЙ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`. Дальше он обновляется каждые 6 часов.

## Если что-то не обновляется

Открой последний запуск в Actions и посмотри лог шага Fetch fresh stats. Каждый источник пишет `✓` или `✗` с причиной. Если источник упал, на сайте остаются его прошлые значения, остальные обновляются как обычно.

Частые причины: не добавлен секрет, закрыт профиль, неверный ник в `config.json`. Репозиторий без активности GitHub может остановить по расписанию через 60 дней, тогда просто нажми Run workflow.

## Локальный просмотр

```
cd site
python3 -m http.server
```

Открой http://localhost:8000. Обновить данные локально: `STEAM_API_KEY=... node scripts/update.mjs`.
